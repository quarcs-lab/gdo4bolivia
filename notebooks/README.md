# Notebooks

Computational notebooks of the GeoDevelopment Observatory of Bolivia. Every notebook runs in Google Colab (no installation needed) and is paired with a MyST markdown file (`.md`) through [jupytext](https://jupytext.readthedocs.io/) for readable diffs. They load their data with the `geo4bolivia` package and run their analyses with its functions (maps with `geo.map`, Moran's I and LISA clusters, convergence, rank mobility, inequality and its decomposition, regression and spatial models, MGWR), each of which returns an interactive figure, a table and a reading of the numbers in words. Other libraries come in only where the package has no function, such as scikit-learn and xgboost for machine learning, or the companion packages expdpy and geometrics for a specialised method. The package has its own repository, [quarcs-lab/geo4bolivia](https://github.com/quarcs-lab/geo4bolivia), and [documentation](https://quarcs-lab.github.io/geo4bolivia/), whose guides and articles come with notebooks of their own.

The six ESDA notebooks are ports of [DS4Bolivia](https://github.com/quarcs-lab/ds4bolivia)'s notebooks, centred on the Multidimensional Poverty Index (`sdg1_2_mpi`) of the SDG Atlas of Bolivia 2026, near the 2012 and 2024 censuses, for the 343 municipalities and indigenous autonomies; the parts that use night-time lights, gridded population or satellite embeddings cover the 339 municipalities of the 2015 map those were computed on (`map339`), and pass `map="map339"` to the spatial functions when they merge them with the SDG data.

## Running locally

```bash
uv sync                                   # the environment: geo4bolivia with every extra, scikit-learn, xgboost, expdpy, geometrics, ...
uv run jupyter lab                        # open notebooks
uv run jupytext --sync notebooks/*.ipynb  # keep .ipynb and .md in sync after editing
```

In Colab, every notebook installs what it needs only if it is missing: `geo4bolivia`, with the extra a method requires (`"geo4bolivia[mgwr]"` for `geo.mgwr`, `[dynamics]` for Markov transitions, `[panel]` for panel models, `[raster]` for `geo.zonal`), and any other library it uses. Outside the repository the package reads the data from GitHub; inside it, the local files. Locally, `uv sync` installs the package from PyPI, or from a checkout next to this repository while a version is in development (`[tool.uv.sources]` in `pyproject.toml`).
