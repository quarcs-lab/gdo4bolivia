# Notebooks

Computational notebooks of the GeoDevelopment Observatory of Bolivia. Every notebook runs in Google Colab (no installation needed) and is paired with a MyST markdown file (`.md`) through [jupytext](https://jupytext.readthedocs.io/) for readable diffs. They load their data with the `geo4bolivia` package. The six ESDA notebooks are ports of [DS4Bolivia](https://github.com/quarcs-lab/ds4bolivia)'s notebooks, centred on the Multidimensional Poverty Index (`sdg1_2_mpi`) of the SDG Atlas of Bolivia 2026, near the 2012 and 2024 censuses, for the 343 municipalities and indigenous autonomies; the parts that use night-time lights, gridded population or satellite embeddings cover the 333 units whose territory did not change since the map those were computed on.

## Running locally

```bash
uv sync                                   # create the environment (includes geo4bolivia, scikit-learn, xgboost, mgwr, ...)
uv run jupyter lab                        # open notebooks
uv run jupytext --sync notebooks/*.ipynb  # keep .ipynb and .md in sync after editing
```

In Colab, every notebook installs what it needs (`geo4bolivia`, `mapclassify`, `esda`, `mgwr`, ...) only if it is missing. Outside the repository the package reads the data from GitHub.
